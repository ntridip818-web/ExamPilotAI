# 🚀 ExamPilotAI

> Never Miss an Opportunity.

ExamPilotAI is an AI-powered government exam and career management platform for India.

## Vision

To become India's most trusted platform for government exam notifications, reminders, and career opportunities.

## Mission

Help every student receive verified official information at the right time.

## Core Features

- Government Exam Notifications
- Smart Reminders
- Exam Calendar
- AI Career Recommendations
- Official PDF Links
- Saved Exams
- Personal Dashboard
- Multi-State Support

## Tech Stack

- Flutter
- FastAPI
- PostgreSQL
- Firebase
- OpenAI
